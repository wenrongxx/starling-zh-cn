## 项目

把 **Starling**（Minecraft Java 版的安卓启动器，Rust 写的）界面汉化成简体中文。

**范围**：只做**启动器**（Launcher）——侧边栏、设置子页面、皮肤/披风、控件编辑器、Starling Control Hub、设置向导、下载页、钓鱼小游戏。**游戏内 Minecraft 的文案一律不管。**

测试环境：用户的小米手机（HyperOS 4，Android 17）；开发机 Windows + macOS（<build-host-ip>，编译）+ Android 模拟器（在 Mac 上，已开窗口到桌面）。

## 必读的坑（前任踩过，别重复）

1. **源码树必须同步**：`src_zh/i18n_zh.rs` 与源码树的同名文件要双向 `cp` 同步，改完 `grep -c` 验证。前任在这栽过两次（脚本用旧副本覆盖新代码，导致"改了没生效"）。
2. **tar 整目录推送会覆盖 Mac 上的改动**——推之前先确认本地树是最新的。改单个文件优先只 scp 那一个文件。
3. **Python 切片改 hud.rs 曾引入语法错误**（多收一个 `}`），导致构建脚本 panic。改完必须编译验证。
4. **hud.rs 含非 UTF-8 字节**，Python 读写必须 `errors='surrogateescape'`。
5. **模拟器默认直接进游戏**！进启动器要走：游戏内左上角 H 按钮 → Hub 右上角「启动器」→ 退出 → 重开 Activity。前任在这里扫错了半天游戏画面。
6. **子串替换要用整词边界**，否则会把 Gameplay 切成「游戏play」。
7. **语言文件是整文件替换不是逐键合并**——皮肤包的 zh_cn.json 会顶掉游戏自带的，必须合并成完整一份。
8. **Windows PowerShell → ssh**：远程命令里别用双引号（会被吞）、裸 `*` 会被 Mac zsh 展开；单引号包整个命令。详见 HANDOVER.md 第十一节。
